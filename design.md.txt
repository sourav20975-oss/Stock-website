# Stock Knowledge SaaS — Design System

## 1. Design Direction

Create a **professional Indian stock-market research platform** inspired by the usability and information density of established brokerage platforms such as Angel One, Dhan, Zerodha, and institutional market terminals.

The design must feel like a real financial product.

### Do NOT use

* Glassmorphism
* Excessive transparency
* Huge gradients
* Neon backgrounds
* Floating glowing cards
* Purple AI gradients
* Excessive rounded cards
* Futuristic sci-fi UI
* Excessive animations
* Giant hero sections
* AI-generated-looking dashboards

### Use

* Solid surfaces
* Clear borders
* Compact spacing
* Strong typography
* Dense financial tables
* Tabular numbers
* Professional charts
* Clear positive/negative states
* Consistent navigation
* Practical buttons
* Subtle shadows only where useful
* Responsive layouts

# 16. GMP Design

GMP must have an explicit label:

```text
Grey Market Premium
Unofficial / Indicative
```

Example:

```text

₹85

~19.3%

```

Never visually present GMP as an official exchange price.

# 30. Tables

Tables should feel like financial software.

Characteristics:

* compact rows
* subtle borders
* right-aligned numbers
* sticky headers where useful
* hover state
* clear sorting
* responsive mobile transformation

```text

TCS        ₹3,421.25    +1.42%       42.42L
INFY       ₹1,523.10    -0.41%       31.21L
```

Numbers should be right aligned.

# 36. Accessibility

Must support:

* keyboard navigation
* visible focus states
* semantic buttons
* accessible labels
* sufficient contrast
* readable font sizes
* screen-reader labels
* reduced motion preference

Never make information dependent on hover.

---

# 37. Animation

Keep animation minimal.

Allowed:

```text
button loading
skeleton
small dropdown transition
tab transition
chart tooltip
```

Avoid:

```text
floating cards
glowing borders
background particles
scrolling gradients
3D animations
large entrance animations
```

Finance software should feel fast.

# 40. UX Rules

### Rule 1

Important financial information must be visible without opening multiple dialogs.

### Rule 2

Numbers must be easy to scan.

### Rule 3

Every dynamic number should have a freshness indicator where relevant.

### Rule 4

Positive/negative colors should have semantic meaning.

### Rule 5

AI should support the financial product, not visually dominate it.

### Rule 6

Charts should be functional rather than decorative.

### Rule 7

Tables should be used when comparing exact financial numbers.

### Rule 8

Mobile should not be a scaled-down desktop.

### Rule 9

Dark and light themes must both feel intentionally designed.

### Rule 10

Never sacrifice readability for visual effects.

---

# 41. Final Visual Target

The final application should feel approximately like:

```text
Professional brokerage UI
        +
Market research terminal
        +
IPO research platform
        +
Modern SaaS usability
        +
Subtle AI assistance
```

The visual language should be:

```text
Solid surfaces
Thin borders
Compact spacing
Strong typography
Professional blue accent
Green/red financial semantics
Clean charts
Dense tables
Minimal animation
Excellent responsive behavior
```

The final result should look like a **real financial product**, not an AI-generated template.
